## 实际口令（成片用的就是这一版）

澳门大学在本次环境里能稳定返回候选，所以没有改用「附近的麦当劳」。选的是第一个候选，再说「最快的」开始导航。限速没有单独提问；导航 HUD 上直接显示车速。

### 1. 唤醒并回答能做什么

1. 应用已在前台，地图可见。
2. 说：「你好小诺。」
3. 预期：会话从休眠进入激活。
4. 说：「你能帮我做些什么？」
5. 预期：小诺用语音回答，气泡里出现导航、播放音乐、调节空调、查看摄像头、打电话。说完到开口约 1.7 秒。右侧字幕写的是同一个千帆 Flex 会话：语音进去，语音出来，工具调用也在这段会话里。

### 2. 自然语言导航（主场景）

1. 说：「你好小诺。」
2. 说：「带我去澳门大学。」
3. 预期：调用 `navigate_to`，高德返回 5 个候选，屏幕列出澳门大学横琴校区等地点，小诺请用户说第几个或点选。
4. 说：「第一个。」
5. 预期：选中第 1 个候选，算出 2 条路线（约 5.4 km / 15 分钟与 6.4 km / 17 分钟）。
6. 说：「最快的。」
7. 预期：选中最快路线，高德导航 SDK 启动。小诺说已开始前往澳门大学横琴校区。HUD 出现转向（进入环岛东路辅路）、车道和约 50 km/h。随后有高德转向播报。说完到导航启动约 1.9 秒。

若「澳门大学」这一轮没有候选，改说：「带我去拱北口岸。」其余步骤不变。拱北口岸在 9 月 28 日的演示里通过过。

### 3. 多轮上下文（空调）

同一会话里连续说，不要重复「空调」：

1. 「你好小诺。」
2. 「打开空调。」预期：本地执行成功。
3. 「温度调到二十四度。」预期：空调开、24°C、风量 2，小诺确认。
4. 「再凉一点。」预期：按上一轮温度理解，调到 23°C。底栏显示 23°。

### 4. 播放音乐

1. 「你好小诺。」
2. 「来首歌听听吧。」
3. 预期：调用 `control_music` 且执行成功后，小诺才说已经播放。底栏播放按钮变成暂停。

全片约 3 分钟。不要再加场景。

## 怎么录

调试包已装在模拟器上，不要重装，不要清数据。不要打开设置，不要让密钥入画。模拟器屏幕必须亮着，否则 `screenrecord` 会报 `INVALID_LAYER_STACK`。

工具在 `D:\桌面\android_doc\gba_demo_2026-09-30\tools\`。`adb` 使用 `C:\Users\Administrator\Android\Sdk\platform-tools\adb.exe`。音频桥复用仓库里的 `tools/speech-harness/host_audio_bridge.py`（调试包的 `HostAudioBridge`，端口 7790）。

```powershell
cd D:\桌面\android_doc\gba_demo_2026-09-30
python tools\make_clips.py
python tools\demo_rec.py chat takes\s1_chat --record --ask help_what
python tools\demo_rec.py nav takes\s2_nav --record --dest nav_um --pick first
python tools\demo_rec.py multiturn takes\s3_multi --record
python tools\demo_rec.py music takes\s4_music --record --ask music_song
python tools\compose.py
```

`compose.py` 里的 `SCENES` 要改成这次采用的 take 目录名，并按日志裁掉每段开头的空等。成片输出为同目录的 `gba_it_competition_demo.mp4`，竖屏拼接为 `gba_it_demo_raw.mp4`。

每段先看日志里的 `transcript=`、`tool=` 和 `nav_navigation_started`。不对就整段重录。不要把失败的口令剪成看起来成功。

## 失败时怎么收回

| 现象 | 处理 |
| --- | --- |
| 没唤醒 | 确认桥已连上（日志有 bridge）。再说一次「你好小诺」。不要在高德正在播报时说话。 |
| 导航没有候选 | 改用 `nav_gongbei`（「带我去拱北口岸」）。 |
| 「第一个」被理解成路线偏好 | 等候选列表出现并且小诺说完，再重说「第一个」。 |
| 空调或音乐没执行 | 整段重录。音乐这一段历史上要多次才稳定，以底栏变成暂停为准。 |
| 屏幕录像没有声音 | 正常。声音来自电脑上对齐的用户 PCM 和小诺真实回复。 |
| 画面里出现设置或密钥 | 丢掉该段，不要用。 |
